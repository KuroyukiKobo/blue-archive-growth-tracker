# 画面ワイヤーフレーム（プロトタイプ）

## 前提

- デスクトップとモバイルで同じ主要操作を使える。
- キャラクター名はマスターから選択し、自由入力はしない。
- 入力値は現在値のみ。保存先はlocalStorage。
- `0` は実値、空欄は未入力として区別する。

## 一覧画面

```text
┌──────────────────────────────────────────────────────────────┐
│ 育成状況管理                         先生Lv [ 90 ] [保存]      │
├──────────────────────────────────────────────────────────────┤
│ 所持キャラ 1                         [名前で検索...] [＋追加] │
├──────────────────────────────────────────────────────────────┤
│ アル                                                        › │
│ ★3   Lv90   絆 20   スキル 5/10/10/10   応用WB 0/25×3        │
├──────────────────────────────────────────────────────────────┤
│ ※ データはこのブラウザに保存されます                         │
└──────────────────────────────────────────────────────────────┘
```

### 操作

- 先生Lv変更は共通設定として保存する。値域は1〜マスター上限。
- 検索は日本語名の部分一致。衣装違いは個別の結果として表示する。
- キャラクター行選択で編集画面を開く。
- 追加では未所持キャラクターだけを選択候補にする。
- 0件の場合は「登録キャラクターなし」と追加操作を表示する。

## キャラクター選択

```text
┌──────────────────────────────────────────────┐
│ キャラクター追加                       [戻る] │
├──────────────────────────────────────────────┤
│ [キャラクター名で検索....................]   │
│                                              │
│ アル                                 [追加]  │
│ アル（別衣装）                       [追加]  │
└──────────────────────────────────────────────┘
```

すでに所持登録済みのキャラクターは一覧から除外する。マスター未登録キャラクターの自由入力欄は設けない。

### 入力・保存ルール

- キャラクター名はマスター表示のみで編集不可。
- スキルは各スキルのマスター上限を超えて入力できない。
- WBは各0〜25。初期値0と未入力は異なる状態。
- 絆上限は現在の★に連動。★を下げた際に既存絆値が上限を超える場合は、値を消さず警告して保存を止める。
- 未解放装備枠は読み取り専用表示。キャラLvを上げて解放されたら入力可能。
- 固有武器の未解放条件を満たさない場合、入力欄を無効化し現在値を保持する。
- 愛用品対象外キャラクターには欄を表示しない。対象キャラは「未所持/T1/T2」を選択する。
- キャンセル時は編集開始時の値へ戻す。削除は確認ダイアログ後に確定する。
- 保存失敗時は入力値を維持し、一覧へ戻さない。

## モバイル配置

- 一覧は1列表示とし、育成概要はキャラクター名の下に折り返す。
- 編集項目は基本、スキル、能力解放、装備、固有武器・愛用品の順に縦積みする。
- 能力解放の3属性は狭い画面では縦並びにする。
- 保存・キャンセル操作は画面下部で見つけやすくする。
